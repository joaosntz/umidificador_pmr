1. Clonar o repositório:
Baixe o projeto usando o comando git clone https://github.com/joaosntz/umidificador_pmr.git ou baixando o arquivo ZIP direto do site.
2. Abrir no VS Code:
Abrir a pasta raiz do projeto (onde fica o arquivo platformio.ini).
3. Instalar as Extensões:
Precisa ter instalado no VS Code:
	• PlatformIO IDE
	• Wokwi Simulator
4. Iniciar a Simulação:
Com o projeto aberto, basta pressionar F1 (ou Ctrl + Shift + P), digitar Wokwi: Start Simulator e selecionar o arquivo de diagrama (geralmente o diagram.json).
O PlatformIO vai baixar automaticamente as bibliotecas e o compilador necessários na primeira execução.
